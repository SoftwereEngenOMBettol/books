# هُــنـا — Landing Page

صفحة تعريفية (Landing Page) لمتجر **هُــنـا**، وهو متجر أدلة رقمية عربية (تطوير ذات، مبيعات وتسويق، تجارة إلكترونية، بناء ثروة). الدفع والتحميل يتمّان بالكامل عبر [Gumroad](https://herewe.gumroad.com/) — هذه الصفحة للعرض والتصفّح فقط.

🔗 **المتجر (الدفع):** https://herewe.gumroad.com/

## المحتوى

- صفحة واحدة (`index.html`) — HTML/CSS خالص، بدون أي تبعيات بناء (build tools).
- تصميم عربي بالكامل (RTL)، بأقسام:
  - تطوير الذات والعقلية
  - المبيعات والتسويق
  - التجارة الإلكترونية والمنتجات الرقمية
  - بناء الثروة والأعمال
- غلاف SVG مصمَّم لكل منتج (بدون صور خارجية أو تبعيّة على مصادر مدفوعة).
- كل زر "اشترِ الآن" يفتح رابط صفحة المنتج الصحيح على Gumroad مباشرة.
- الخطوط عبر Google Fonts: `Aref Ruqaa` (العناوين)، `Cairo` (النصوص)، `Tajawal` (تفاصيل صغيرة).

## التشغيل محلياً

لا يحتاج أي تثبيت. فقط افتح الملف في المتصفح:

```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

أو شغّل خادماً محلياً بسيطاً أثناء التطوير:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

1. ادفع الملفات إلى فرع `main` (أو أي فرع تختاره).
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر الفرع والمجلد الجذري (`/root`)، ثم احفظ.
4. الصفحة ستكون متاحة على رابط من نوع:
   `https://<username>.github.io/<repo-name>/`

## تعديل المنتجات

كل منتج في `index.html` عبارة عن كتلة `<div class="card">` تحتوي:

- غلاف SVG داخلي (قابل للتعديل مباشرة كنص/رسم).
- عنوان المنتج (`<h3>`).
- وصف قصير (`<p>`).
- السعر ورابط الشراء (`<a class="btn-card" href="...">`).

لإضافة منتج جديد: انسخ كتلة `<div class="card">` كاملة داخل القسم المناسب، وعدّل الغلاف والعنوان والرابط والسعر.
